# General MONDAY Core release

Release: `0.1.0+codex.20260923220628`

This release made the primary `monday` plugin self-contained as MONDAY's operating intelligence. Global personalization retains identity, values, durable preferences, and the high-level instruction to begin with `monday-core`; the plugin owns reusable orchestration.

Verified capabilities include cross-domain intake and routing, the complete capability registry, canonical source selection, evidence labels, project and personal boundaries, journal ownership, approval boundaries, synthesis and QA routing, and schema-3 Command Center publication/readback. Atlas, Nexus, and CRG Notebook Reviewer remain independent plugins.

This milestone predates and is distinct from the master-roadmap Priority 1 dependable daily system.
