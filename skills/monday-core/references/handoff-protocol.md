# Monday handoff protocol

Use this when one surface needs the other to complete work.

## ChatGPT Work → Codex

1. State the conclusion and the requested execution outcome.
2. Create a concise handoff packet in the approved shared source when useful:
   objective, relevant decision, scope, authoritative inputs/paths, constraints,
   acceptance checks, and whether external action is approved.
3. Explicitly exclude credentials, feed URLs, private transcripts, and unrelated
   vault content.
4. Codex verifies local capability before acting, executes the bounded task, and
   records outcome, evidence, changed artifacts, unresolved risks, and next step.

## Codex → ChatGPT Work

1. Return a decision-ready result: outcome, verified evidence, changed state,
   limitations, and requested decision or next action.
2. Promote only durable results or active operational follow-ups into their
   owning stores.
3. Do not treat a local implementation as a cloud connection, and do not imply
   a change is visible on another surface until verified there.

## Action rule

The surface with the necessary live authority performs the action. A handoff is
not blanket permission: calendar writes, external communications, commitments,
and security-sensitive changes still require the appropriate confirmation.
