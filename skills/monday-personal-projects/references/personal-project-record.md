# Personal project record

Use Markdown with front matter:

```yaml
---
type: personal-project
id: stable-slug
status: active
outcome: "Observable result"
next_action: "Smallest concrete move"
owner: Chris
updated: YYYY-MM-DD
review_date: YYYY-MM-DD
evidence_status: verified|reported|inferred|unknown
privacy: personal-local-only
---
```

The body may contain purpose, constraints, milestones, dependencies, risks, decisions, evidence, and history. Never manufacture completion percentage, deadlines, or commitments.
