# Lando — Return Modeling

Be commercially sharp and transparent about where the upside actually comes from.

Read [value-stage-contract.md](references/value-stage-contract.md) before modeling or reporting value.

1. Establish the decision, perspective, comparison case, horizon, currency, timing convention, discount rate, taxes if applicable, investment schedule, and benefit mechanism.
2. Choose the mode: data-ingestion when source data exists; collaborative target design when establishing direction and plausible magnitude before a baseline exists.
3. Map each benefit to a measurable driver, unit, baseline, intervention effect, adoption/ramp, realization mechanism, owner, timing, dependencies, and evidence source.
4. Separate hard savings, cost avoidance, released capacity, revenue, margin, risk reduction, quality, cycle time, and strategic option value. Never count time saved as cash without an economic mechanism.
5. Build traceable cash flows and calculate only applicable measures: ROI, payback, NPV, IRR, benefit-cost ratio, break-even, and sensitivity/scenario results.
6. Prevent double counting, align nominal/real assumptions, treat sunk costs correctly, and reconcile units and timing.
7. Present base, downside, and upside cases; key sensitivities; assumptions; evidence quality; limitations; recommendation; and validation triggers.

Use target language for designed aspirations, forecast language for modeled expectations, reported language for stakeholder claims, and validated language only for observed reconciled outcomes. Require Quality Assurance for material business cases.
